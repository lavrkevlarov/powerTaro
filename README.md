# 🔮 Таролог

Веб-приложение для раскладов Таро. Работает на телефоне и на компьютере, его можно установить на главный экран как приложение (PWA), без интернета оно тоже работает.

## Возможности

- **Три способа задать вопрос:** написать, продиктовать голосом (Web Speech API, русский язык) или загадать про себя.
- **5 раскладов:** «Одна карта», «Прошлое · Настоящее · Будущее», «Ситуация · Препятствие · Совет», «Отношения», «Крест судьбы».
- **Ритуал с анимацией:** колода появляется, тасуется и снимается, потом раскрывается веером. Карты можно выбрать самому или доверить выбор колоде. Выбранная карта перелетает на стол и переворачивается в 3D, вокруг вспыхивают искры.
- **Разбор сразу:** толкование каждой карты с учётом позиции и темы вопроса (любовь, работа, деньги, здоровье, путь). Итог учитывает стихии, Старшие Арканы, перевёрнутые карты и известные сочетания карт. Если вопрос задан в форме «да/нет», приложение даёт ответ, а в конце даёт совет карт.
- **Озвучка разбора** (синтез речи), кнопка «Поделиться», **история** последних 30 раскладов.
- **Живой фон:** звёздное небо с параллаксом и падающими звёздами.

## Авторская колода

Все 78 карт нарисованы кодом в SVG (`js/art.js`) в собственном стиле «Звёздная гравюра»: золотые линии на ночном фоне, у каждой масти свой цвет. Есть небольшие встроенные анимации: вращается Колесо, мерцают звёзды, качаются Весы. Иллюстрации классических колод (Райдер–Уэйт и других) не используются. Тексты значений тоже написаны с нуля.

## Запуск

Сборка не нужна, это статические файлы.

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Голосовой ввод работает только по `https` или на `localhost`, в Chrome, Edge и Safari. Для публикации подойдёт GitHub Pages: Settings → Pages → ветка с проектом.

## Структура

| Файл | Что внутри |
|---|---|
| `index.html` | разметка экранов |
| `css/style.css` | стили и CSS-анимации |
| `js/cards.js` | 78 карт и их значения |
| `js/art.js` | генератор иллюстраций карт и рубашки |
| `js/reading.js` | расклады, определение темы, текст разбора |
| `js/sky.js` | анимированное звёздное небо |
| `js/app.js` | интерфейс, тасование, веер, полёт и переворот карт |
| `sw.js`, `manifest.webmanifest` | офлайн-режим и установка как приложения |
